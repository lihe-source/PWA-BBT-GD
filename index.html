首次設定與多人共用說明
  1. 在 Google Cloud 啟用 Google Drive API，建立 Web 類型 OAuth Client ID。
  2. OAuth「已授權的 JavaScript 來源」填入 GitHub Pages 的來源網域，例如 https://你的帳號.github.io，不含專案路徑。
  3. OAuth 測試階段，將要使用的 Google 帳號加入測試使用者。
  4. 共同記錄同一人時，將同一個 Drive 資料夾共用給對方，設為編輯者；不同女性請使用不同資料夾。

此版本採 Drive 讀寫授權，程式僅操作指定資料夾。OAuth 授權範圍本身較廣；正式公開使用須依 Google 規範完成驗證。請勿填入 Client Secret 或服務帳戶私鑰。

授權過期時可能需要重新按連線；關閉程式後不保證背景同步。回到程式且授權有效時會自動補傳。
